# Service template

`service.html` is the static service template, using Backend Development as its example.
Edit the HTML directly, as with `technologies/technology.html` and `industries/industry.html`.

- Section layout follows the backend development reference, with the site's light theme.
- Use `section > .page-container`, flex layouts, the existing buttons, and global heading styles.
- Put layout classes on the tags and use standard Tailwind `max-*` breakpoints. Keep only Swiper state styles in `src/styles/pages/service.css`.
- The bottom inquiry form uses the compact Technology/Industry layout and the existing `main.js` and `service.js` handlers.
- The form prepares an email request; it does not send submissions to a server.

Run `npm run build:css` after editing classes. Edit this static template directly; it is not generated by `build:services`.

Portfolio previews link to the published KKEYDOS projects. The testimonials reuse the homepage's client reviews. Both carousels use the bundled Swiper with touch gestures, arrow buttons, pagination, and focused keyboard navigation (arrows, Home, End). They show one slide on mobile, two on tablets, and three on desktop. Reviews follow the reference's staggered desktop composition and stack normally below 1024px. Reduced-motion preferences disable carousel transitions.
